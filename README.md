# Estudos-JavaScript — 7 dias, 7 projetos

Sete mini-projetos em JavaScript puro, um por dia, feitos em 2021 com a didática do **Bonieky Lacerda**. Cada pasta é independente e abre direto no navegador.

> Projeto de estudo.

## Projetos

| Dia | Pasta | O que faz | Conceitos |
|-----|-------|-----------|-----------|
| 1 | `1 dia - Bateria/` | Bateria tocada pelo teclado (Q, W, E, A, S, D, Z, X, C), com composição de sequências | `keydown`, `Audio`, `setTimeout` |
| 2 | `2 dia - Relógio Analógico/` | Relógio com ponteiros analógicos e hora digital | `setInterval`, `Date`, `transform: rotate` |
| 3 | `3 dia - Clima/` | Busca o clima de uma cidade na API da OpenWeather | `fetch`, `async/await`, JSON |
| 4 | `4 dia - Jogo da Velha/` | Jogo da velha para dois jogadores, com verificação de vitória e empate | estado do jogo, eventos de clique |
| 5 | `5 dia - Desenhando no Canvas/` | Quadro para desenhar com o mouse, com seleção de cores e limpeza | Canvas 2D, eventos de mouse |
| 6 | `6 dia - Quiz/` | Quiz de múltipla escolha com pontuação final (`questions.js`) | renderização dinâmica, arrays |
| 7 | `7 dia - Arrasta e Solta/` | Organizar itens arrastando entre áreas | Drag and Drop API |

Cada pasta também tem o arquivo `js_*_base.zip`, o material-base do curso.

## Como rodar

Abra o `index.html` da pasta desejada no navegador. Não há dependências nem build.

**Clima:** precisa de uma chave própria da [OpenWeather](https://openweathermap.org/api), colocada em `script.js`. Não publique a sua chave no repositório.

## Tecnologias

HTML5, CSS3 e JavaScript ES6+.
